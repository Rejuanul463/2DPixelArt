# Fix Plan: Google Play Games Compilation Error

## Problem
The script `Assets/Scripts/PlayFab/PlayFabAuthService.cs` has compilation errors because:
- Lines 7-8 import `GooglePlayGames` namespaces wrapped in `#if UNITY_ANDROID`
- The Google Play Games plugin is NOT installed in the project
- `UNITY_ANDROID` is defined when Android Build Support is installed in Unity, causing the compiler to try to import non-existent namespaces

## Solution: Remove Google Play Games Code

### Changes to make in `PlayFabAuthService.cs`:

1. **Remove the using statements** (lines 6-9):
   - Delete the `#if UNITY_ANDROID` block with `GooglePlayGames` imports

2. **Remove the `LoginWithGoogle` method body** (lines 106-150):
   - Replace the Android-specific implementation with a simple error message
   - Keep method signature but show "not available" message

### Specific edits:

#### Edit 1: Remove using statements (lines 6-9)
```csharp
// DELETE these lines:
#if UNITY_ANDROID
using GooglePlayGames;
using GooglePlayGames.BasicApi;
#endif
```

#### Edit 2: Simplify LoginWithGoogle method (lines 108-148)
Replace the entire method body with:
```csharp
public void LoginWithGoogle(bool rememberMe = false)
{
    OnLoginFailure?.Invoke("Google Sign-In requires Google Play Games plugin. Please install the plugin or use another sign-in method.");
}
```

This removes all Google Play Games dependencies while keeping the method signature for API compatibility.
